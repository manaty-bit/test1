公式・性質集

条件・意味・例題をまとめて確認。レベル2・3の復習に。

REFERENCE

① 対数の定義

ap = M ⇔ logaM = p

底を何乗すれば真数になるかを表す。

25 = 32 ⇔ log232 = 5

② 積 → 和

loga(MN) = logaM + logaN

真数のかけ算は、対数の和に変わる。

log24 + log28 = log232 = 5

③ 商 → 差

logaMN = logaM − logaN

真数のわり算は、対数の差に変わる。

log381 − log39 = log39 = 2

④ 累乗の公式

logaMr = r logaM

真数の指数を前に出せる。

log2√8 = 12log28 = 32

⑤ 底の変換公式

logaM = logcMlogca

分子が真数、分母が元の底。新しい底 c は任意に選べる。

log48 = log28log24 = 32

⑥ 特別な値・逆の関係

loga1 = 0 / logaa = 1
alogaM = M

0乗すると1、1乗すると底そのもの。

log51 = 0　・　log55 = 1

⑦ 底が逆数の場合

log1/aM = −logaM

底を逆数にすると、対数の符号が変わる。

log1/28 = −log28 = −3

⑧ 底の変換をつなげる

logab × logbc = logac

間にある底がつながる。複合問題で便利。

log23 × log38 = log28 = 3
条件：対数の底は 0 より大きく 1 ではない数、真数は正の数。上の公式では a,c などの底は同様の条件を満たし、M,N などの真数は正です。特に、loga(M+N) は logaM + logaN に変形できません。
