    DETECTIVE'S NOTEBOOK
    📖 捜査手帳
    正確な証明をつくるための基本ルールだ。迷ったらいつでも確認しよう。
    合同条件はこの3つだけ
    1. 3組の辺がそれぞれ等しい。
    2. 2組の辺とその間の角がそれぞれ等しい。
    3. 1組の辺とその両端の角がそれぞれ等しい。
    対応する順番（最重要）
    △ABC ≡ △DEF なら、頂点Aと頂点D、頂点Bと頂点E、頂点Cと頂点Fがそれぞれ対応する。たとえば AB = DE、∠ABC = ∠DEF だ。合同の証明では、角の3文字も左と右で同じ位置に対応する頂点が来るように書こう。 ∠QOP の Q-O-P に対応する頂点が R-O-P なら、∠QOP = ∠ROP と記す。正しい対応を保った並べ替え（△BCA ≡ △EFD など）も数学的には正しい。
    記号と角のルール
    三角形の合同には ≡、辺の長さ・角の大きさの等しさには = を使う。∠ABC の頂点は真ん中の B。∠ABC と ∠CBA は同じ角を表す。逆順だから角の大きさが違うわけではない。ただし、このゲームの「対応順をそろえる」問題では、同じ角でも文字の順が対応しない表記は採用しない。
    正しい式と、正しい理由は別々にチェック
    例えば ∠AOC=∠BOD は対頂角のため等しい。「錯角だから」と書くのは根拠が誤り。角の等式だけを見て、理由まで正しいと判断しないこと。与えられた条件 → 等式 → 等しい理由 → 合同条件 → 合同を一つずつ裏取りしよう。
    調書の基本手順
    ① どの三角形か宣言 → ② 等しい辺・角とその根拠 → ③ 合同条件 → ④ 合同 → ⑤ 対応する辺・角が等しいことから最終結論。
    証拠の捏造は禁止
    「見た目が同じ」は根拠にならない。「2組の辺と1組の角」だけでは、その角が間の角か確認が必要。結論を証拠に用いる循環論法も禁止だ。
    この事件簿で身につく力
    仮定と結論、合同条件、共通な辺、対頂角、平行線の錯角、引き算で示す辺の等しさ、角の二等分線、垂線、合同から平行を導く証明まで、少しずつ挑戦できる。
    平行を示す逆向きの推理
    平行なら錯角は等しい。また、錯角が等しければ2直線は平行といえる。最後の問題では、合同によって対応する角が等しいことを示してから、この逆の性質を利用する。
